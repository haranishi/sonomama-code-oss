# そのままコード — OSS版

開いているページのURLを端末内で二次元コードにする Chrome / Edge 拡張機能です。URLの短縮や中継サービスは使いません。

実装の要件・データ境界・検証条件: [現行設計](docs/current-design.md)。

## 読み込み

1. このリポジトリをダウンロードします。
2. 拡張機能管理画面で「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」で、このフォルダを指定します。

Manifest V3 です。ビルドや外部サーバーは不要です。
URLを取得できない内部ページや、長すぎるURLは警告を表示します。取得できるローカルURLはコードを作成し、別端末では開けない旨を表示します。

## テスト

```sh
npm install
npm run test:unit
npx playwright install chromium
npm run test:e2e
```

ブラウザテストはローカルの Playwright を使います。スクリーンショットは `docs/screenshots/` に生成され、Gitには含めません。

## データと公開範囲

URLはポップアップ内の生成処理に使い、外部へ送信しません。詳細は [プライバシーポリシー](docs/PRIVACY.md) を参照してください。
認証トークンを含むURLを画像として共有すると、そのトークンも相手に渡ります。共有前に内容を確認してください。
