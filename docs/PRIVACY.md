# プライバシーポリシー — そのままコード OSS版

最終更新: 2026-10-03

## 拡張機能の処理

ツールバーのボタンを押したとき、開いているタブのURLを読み取り、端末内で二次元コードを作ります。権限は `activeTab` です。
URLを外部サーバーへ送信する処理、アクセス解析、広告、URLの永続保存は組み込んでいません。
二次元コード生成ライブラリは同梱しています。ポップアップを閉じると、その表示処理は終了します。
保存ボタンで生成画像をダウンロードした場合、その画像は利用者の保存先に残ります。

## 共有時の注意

生成画像にはURLのクエリ文字列も入ります。認証トークンや個人情報を含むURL・画像は共有しないでください。
画像の共有先によるデータの取り扱いは、この拡張機能の管理対象外です。
